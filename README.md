# My Personal Portfolio Website

This is a personal portfolio website built as part of Assignment 2 for the Web Technologies / Web Engineering course.

## Features
- **Responsive Layout**: Designed using HTML5 and Bootstrap 5 CDN.
- **Sections Included**: Navbar, Hero, About Me, Education, Skills, Projects, Contact Form, and Footer.
- **Deployment**: Hosted live on Vercel using GitHub repository integration.

##  Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Git & GitHub
- Vercel
